# DevOps & Linux Server Utilities 🐧

Automated monitoring scripts, container blueprints, and system hardening routines for Linux server administrators and cloud engineers.

## Contents
- **System Metrics**: Real-time CPU, RAM, and disk utilization probes.
- **Docker Orchestration**: Clean boilerplate Dockerfiles and compose stacks.
- **Network Diagnostics**: Socket and port reachability verifiers.

## Usage
```bash
git clone https://github.com/tamirpcchanel-create/devops-system-tools.git
cd devops-system-tools
chmod +x scripts/*.sh
./scripts/health_check.sh
```
